# Insight Report: Search queries with unrecognized terms

## Opportunity Score: 8.0/100
- **Volume Reach:** 123 user reviews (4.5 volume score)
- **Severity Impact:** 11.4% critical pain point rating
- **Primary Failure Mode:** `search_vocabulary_mismatch`
- **Primary Retrieval Type:** `unknown`

---

## The Problem in One Line
Users are attempting to locate photos using arbitrary or nonsensical strings, but the system cannot map these inputs to any indexed content. The mismatch between user vocabulary and the searchable metadata causes the search to return no results.

## Who Is Affected
- **Affected User Corpus:** 123 analyzed verbatim complaints.
- **Source Breakdown:** **App Store**: 6, **Play Store**: 117.

## Where It Breaks Down
- **Primary Failure Mode:** `search_vocabulary_mismatch`
- **Experience Gap:** Users attempt natural retrieval or organization patterns, but encounter friction due to keyword inflexibility, missing categorization options, or degraded search confidence.

## What Users Try (and Fail)
- **Typical Behaviors:** Approximate timeline scrolling, repetitive keyword guessing, album folder scanning, and manual workarounds.
- **Common Outcome:** High frustration, giving up on retrieval, or relying on external cloud/gallery solutions.
